# Viva-Vital
Viva Vital is my graduation project in 2025. It is a health application for monitoring vital measurements.
Features
- User authentication and profiles
- Activity tracking (exercising, measurements, etc.)
- Appointment scheduling with health consultants
- Daily health measurements logging
- Automated appointment reminders
  
Technologies:
- Java
- Android Studio
- php
- Firebase
